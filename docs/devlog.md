## Замечено (вне текущих задач)
_Сюда пишем проблемы и идеи, которые нашли по пути, но не стали делать в рамках своей задачи._
- Нет ограничения числа попыток входа (перебор паролей). Для MVP достаточно длинных паролей, но до прода нужен лимит по IP/логину.

## 2026-11-07
- CRM (DEV-011–016), бэкенд: миграция `0003_crm`, модуль `internal/crm` (клиенты, сделки с историей этапов, задачи с признаком просрочки по дате Алматы, показатели), API `/api/v1/crm/...`, демо-данные в `make seed`. Экраны — следующей задачей.
- sqlc: для `numeric` в `overrides` нужен `db_type: "pg_catalog.numeric"` (без префикса получается pgtype.Numeric); `make test` теперь с `-p 1`, иначе пакеты с общей тестовой базой мешают друг другу (deadlock).
- Старт проекта. Репозиторий `borablad/krgo_crm_mvp`, VPS подготавливается (Ubuntu 22.04, 1 vCPU, 1 ГБ).
- Перенесены бэклог (38 задач) и сценарии приёмки из таблицы заказчика в `docs/`.
- Написаны `CLAUDE.md`, `docs/architecture.md`, `docs/ux.md`.
- Ядро бэкенда: Go 1.27, Huma, pgx + sqlc, goose. Вход по cookie-сессии, 5 ролей и матрица прав, API пользователей, журнал действий, health. Тесты: сквозной сценарий входа и прав, CSRF, защита последнего администратора.
- Грабли sqlc: переопределения типов работают только внутри пакета и с `db_type` без префикса `pg_catalog` (`timestamptz`, а не `pg_catalog.timestamptz`).
- Huma требует уникальных имён типов тел запросов и ответов во всём приложении — правило записано в архитектуру.
- Фронтенд: Vite 8, React 19, TanStack Router (файловые маршруты) и Query, shadcn/ui на Tailwind 4, Golos Text. Вход, каркас с меню, главная, экраны «Пользователи» и «Журнал». Типы API генерируются из OpenAPI (`make api-types`). Проверено в браузере на ширине ноутбука и телефона.
- Деплой: один образ (фронт встроен в Go-бинарник), `deploy/compose.yml` + Caddy, `backup.sh`/`restore.sh`, workflows `ci.yml` и `deploy.yml`. VPS подготовлен: swap 2 ГБ, Docker, порты 80/443, `/opt/cargo-crm/.env`.
- Huma: `DefaultArrayNullable=false`, иначе каждый список в TypeScript становится `T[] | null`.
- Справочники (DEV-006–010), бэкенд: миграция `0002_directories`, API `/api/v1/directories/...`, запись по группам справочников зависит от роли (`canWrite`), удаления нет — только `is_active`; склад создаётся вместе со служебной ячейкой «ПРИЁМКА». Демо-данные — `directories.SeedDemo`. Экраны фронтенда — следующая задача.
- Тесты бэкенда теперь гонять с `go test -p 1`: пакеты делят одну тестовую базу и чистят её друг у друга (в `Makefile` сделано, в CI надо поправить). Справочники `units` и `currencies` тестовая очистка не трогает: их заполняет миграция.
